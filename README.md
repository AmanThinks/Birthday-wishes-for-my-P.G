# 🎂 Birthday Wishes for My P.G ❤️

A special birthday surprise website made with love for someone who makes every moment beautiful. 💖

## 💝 About the Project

This is a personal birthday wishes website created to celebrate a very special person. It includes a romantic design, memorable photos, heartfelt messages, and background music to make the birthday unforgettable.

## ✨ Features

- 💕 Romantic birthday-themed design
- 📸 Photo gallery with special memories
- 💌 Heartfelt birthday wishes and messages
- 🎵 Background music
- 📱 Responsive layout for mobile and desktop
- 🌸 Personalized surprises made with love

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
